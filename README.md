# r_for_beginners
This repository contains a series of useful scripts annotated for ease in navigating the R programming language. No prior computing knowledge is required or expected. These are used as part of a 4 part in-person workshop that use live coding to model exploring R in a relaxed environment. 

COURSE LEARNING OBJECTIVES

By the time you complete this course, you should be able to

• Use R to solve simple tasks in your data

• Understand the programmatic mindset including coding loops, logic, and basic debugging

• Load in and explore data through R (particularly using tidyverse)
